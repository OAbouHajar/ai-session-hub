How it works

One small habit. No lost thread.

  1. 1

    Work normally

    Use GitHub Copilot, Claude Code, OpenAI Codex, or Google Gemini as you already do.

  2. 2

    Wrap the session

    Ask the AI to save where you stopped and what comes next.

  3. 3

    Continue later

    Find the work in your local dashboard and resume with context.

Your local session memory

Search what you remember.

Search by task, project, folder, action, or file. Session Hub shows the provider, files involved, decisions, stopping point, and next action in one place.

  • Runs locally at 127.0.0.1
  • Keeps session data in local SQLite
  • Supports macOS and Windows
  • Works across four major AI CLIs

Quick start

Ask your AI CLI to install it.

Copy this prompt into GitHub Copilot, Claude Code, OpenAI Codex, or Google Gemini.

Installation prompt 
Install AI Session Hub from https://github.com/OAbouHajar/ai-session-hub on this machine.

Detect the operating system first. On macOS, verify git, Node.js 22.13+, and at least one supported AI CLI, then run `./scripts/install.sh --no-open`. On Windows, also verify PowerShell 7 and run `pwsh -File .\scripts\install.ps1 -NoOpen`. Stop on unsupported systems.

Clone the latest main branch into a temporary directory, read the README and matching installer, preserve existing Session Hub data and unrelated AI CLI settings, and configure every detected provider. Verify `http://127.0.0.1:43120/api/health` returns `ok: true`, open the dashboard, and report the installed version, configured providers, and any remaining restart or trust action. Proceed autonomously and only ask before administrator-required or destructive actions.

Prefer to install it yourself? See the macOS and Windows commands.

Your sessions stay on your machine.

AI Session Hub is a local dashboard. It does not upload your session data.
